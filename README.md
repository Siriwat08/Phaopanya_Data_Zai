- = rev2.2 + **แก้เฟส 2 ตามผลตรวจ Task 64** (บั๊กจริง 1 ตัว + ช่องโหว่นโยบาย 2 จุด ใน `54_CleanupPhase2.gs`)
- ผ่านการทดสอบ **121/121 กับข้อมูลจริง 11,961 แถว** (โหลด `00_CleanService.gs` production จริง + แพตช์ cleanThai จริง) — ไฟล์อีก 11 ชิ้น regression ตรง rev2.2 ทุกตัว

**สิ่งที่แก้ (FIX):**
| FIX | อะไร | ผล |
|---|---|---|
| **FIX-1** | บั๊กหน่วยวัด KNN_FAR — โค้ดเดิมเทียบ `v.med` (กิโลเมตร) กับ `MAX_MED_M=3000` (เมตร) → ธงระยะทางไม่เคยติดเลย | แก้เป็นเทียบ `v.med > MAX_MED_M/1000` — ธงติดจริง **9 แถว** (ระยะ 3.4–12.4 กม.) |
| **FIX-2** | หน่วยใน EVIDENCE ของ audit — เดิมพิมพ์ `med=0.3m` (จริง ๆ คือ 0.3 กม.) | แปลงเป็นเมตรจริง → `med=300m` |
| **FIX-3** | นโยบาย "จังหวัด = คิวมือเสมอ" (ตามสเปก SPEC-P2) — เกณฑ์โหวตจังหวัดรอบเดิมอ่อนกว่ามาตรฐาน | เพิ่มธง **V_MANUAL_QUEUE** ทุกแถวที่ V (จังหวัด) จะเปลี่ยน = **22 แถว** ไม่ถูกเขียนอัตโนมัติแม้แต่เซลล์เดียว |

- เปลี่ยนหัวคอลัมน์รายงาน `KNN_MED_M` → `KNN_MED_KM` (ค่าเป็นกิโลเมตรจริง)
